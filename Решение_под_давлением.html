Решение под давлением

Сравните варианты, соберите только те данные, которые могут изменить выбор, и примите решение до запуска проекта.

Ситуация Вы руководите проектной командой. До запуска осталось три недели. Ключевой подрядчик сообщил, что задержит свою часть работы минимум на семь дней.
Этап 1 из 3

Проследите последствия на два шага вперед

Что нужно сделать
  1. Посмотрите на три возможных решения.
  2. У каждого уже показано непосредственное последствие.
  3. Нажмите «Показать следующий эффект» у всех трех вариантов.
  4. Переходите дальше только после того, как сравните последствия второго уровня.
Этап 2 из 3

Выберите три факта, которые стоит запросить

Правила
  1. У вас есть только 3 запроса из 6 возможных.
  2. Нажмите «Запросить факт», чтобы открыть данные.
  3. Выбирайте информацию, которая способна изменить решение или оценку риска.
  4. После третьего запроса кнопки остальных фактов заблокируются.
Использовано запросов: 0 из 3 лимит 3
