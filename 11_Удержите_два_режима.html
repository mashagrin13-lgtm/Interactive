Шаг 8

Посмотрите на свою модерацию целиком

Хорошая сессия удерживает два противоположных движения: сначала расширяет поле, затем осмысленно его сужает.

Задача→ правила генерации→ расширение поля→ явное переключение→ критерии→ сравнение→ 2–3 гипотезы→ следующий шаг
Ранняя оценка
—
Покажет, удалось ли не схлопнуть генерацию раньше времени.
Переход к выбору
—
Покажет, удалось ли после генерации действительно перейти к решению.
Нажмите «Проверить», чтобы получить итог по своей модерации.

Памятка

Если команда только генерирует, встреча заканчивается длинным списком без решения. Если сразу оценивает, она получает решение без достаточного выбора. Роль модератора — вовремя менять правила обсуждения.
Задача → правила генерации → расширение поля → явное переключение → критерии → сравнение → 2–3 гипотезы → следующий шаг
