Шаг 2

S + C: замените и объедините

Выбирайте изменение, которое реально сокращает работу и не убирает обязательную проверку.

SЗаменить

Заменить ручной перенос данных автоподстановкой.
Заменить менеджера другим сотрудником.
Заменить индивидуальные предложения одним общим документом.
Заменить согласование устным обещанием.

CКомбинировать

Объединить сбор данных с проверкой обязательных полей.
Объединить все этапы в одну большую встречу.
Объединить предложения для разных клиентов.
Объединить расчет и финальное оформление.
Шаг 3

A + M + P: ищите новые ходы

AАдаптировать

Взять из заявки на кредит проверку обязательных полей до начала расчета.
Взять из презентаций красивую анимацию появления блоков.
Добавить еще один этап ручного согласования.

MМодифицировать

Сократить шаблон до блоков, которые действительно меняются от клиента к клиенту.
Увеличить число страниц, чтобы предложение выглядело солиднее.
Добавить еще один вариант дизайна для согласования.

PИспользовать иначе

Повторно использовать уже проверенные блоки условий и описаний вместо сборки с нуля.
Повторно отправлять прошлое предложение без проверки актуальности.
Использовать коммерческое предложение как внутренний отчет руководителю.

Памятка

SCAMPER полезен не сам по себе. Он нужен, чтобы последовательно менять выбранный объект и получить несколько новых конфигураций, а затем вернуть их к исходной задаче.
